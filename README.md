
# AyushBot - Basic Chatbot

## About
AyushBot is a simple rule-based chatbot built using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Responds to greetings like hello, hi, and hey
- Answers how are you
- Tells the bot's name
- Provides help instructions
- Exits when the user types bye

## Technologies Used
- Python
- Conditional statements
- Loops
- Functions
- User input and output

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run:

   python chatbot.py
